# Password Generator 🔐

A fast and customizable password generator application that creates strong, secure passwords based on user-selected criteria.

## 🔗 Live Demo
*Live Demo coming soon*

## 🛠 Built With
- **React**
- **JavaScript (ES6+)**
- **HTML5 & CSS3**
- **Vite**

## ✨ Key Features
- Customizable password length
- Options to include uppercase letters, lowercase letters, numbers, and special symbols
- One-click copy to clipboard functionality
- Clean, intuitive, and responsive user interface

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
